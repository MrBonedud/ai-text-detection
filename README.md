# AI vs. Human Text Classification

A machine learning project to distinguish AI-generated text from human-written text using TF-IDF features and classification models.

## Overview

This project builds and evaluates multiple classification models to detect whether text was written by humans or generated by AI systems (ChatGPT, Claude, Gemini, DeepSeek). The dataset consists of 2,000 balanced samples (1,000 human, 1,000 AI).

**Best Model:** SVM (LinearSVC) with **99.5% test accuracy** and **100% precision** on AI text detection.

## Quick Start

### 1. Install Dependencies

```bash
pip install -r requirements.txt
```

Or set up the virtual environment:

```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
source .venv/bin/activate  # macOS/Linux
pip install -r requirements.txt
```

### 2. Run the Pipeline

Execute all steps in order:

```bash
# Day 0: Build dataset (if needed)
python scripts/00_build_dataset.py

# Day 1: Preprocess text
python scripts/01_preprocessing.py

# Day 2: Extract TF-IDF features
python scripts/02_features.py

# Day 3: Train models and generate confusion matrices
python scripts/03_models.py

# Generate visualizations (word clouds, term analysis)
python scripts/03_visualization.py

# Evaluate all models and save metrics
python scripts/04_evaluation.py
```

### 3. View Results

All outputs are saved to `results/`:

- **Confusion matrices:** `results/confusion_matrices/`
- **Metrics CSV:** `results/metrics/model_comparison.csv`
- **Visualizations:** `results/charts/`

## Scripts Overview

### `01_preprocessing.py`

Cleans raw text by:

- Lowercasing
- Removing URLs, emails, punctuation, numbers
- Tokenizing with NLTK
- Removing stopwords
- Lemmatizing (or stemming with `--use-stemmer`)

**Usage:**

```bash
python scripts/01_preprocessing.py
python scripts/01_preprocessing.py --use-stemmer
```

### `02_features.py`

Converts cleaned text to TF-IDF sparse matrices:

- Fits vectorizer on training data only (prevents leakage)
- Generates 5,000 features with 1-2 word n-grams
- Saves train/test matrices and feature names

### `03_models.py`

Trains three models and generates confusion matrices:

- Logistic Regression
- SVM (LinearSVC)
- Naive Bayes

### `04_evaluation.py`

Evaluates all models with comprehensive metrics:

- Accuracy, Precision, Recall, F1 on both train and test sets
- Generalization gap analysis (detects overfitting)
- Saves full comparison to CSV

### `03_visualization.py`

Generates exploratory visualizations:

- Word clouds for human vs. AI text
- Top 20 TF-IDF terms per class (bar chart)
